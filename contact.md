# Contact

Kaku is a public open source project. Every support channel is public except security reports.

## Bugs and feature requests

Open an issue at [github.com/tw93/Kaku/issues](https://github.com/tw93/Kaku/issues). This is the primary and fastest channel; it is read by the maintainer directly. Search existing issues first, since install and AI setup questions are often already answered.

Include these details to help reproduce the problem:

- Install method: DMG or `brew install tw93/tap/kakuku`.
- macOS version and chip (Apple Silicon or Intel).
- Kaku version, shown by `kaku --version` in your installed app.
- Output of `kaku doctor`, which reports the app bundle, config directory, PATH, shell integration, and optional tools.
- Exact steps to reproduce, and what you expected instead.

## Questions and ideas

For usage questions, configuration help, and open-ended ideas that are not yet a bug, use [GitHub Discussions](https://github.com/tw93/Kaku/discussions). Many answers already live in the [FAQ](https://kaku.fun/docs/faq) and the [Configuration](https://kaku.fun/docs/configuration) page, so those are worth a look first.

## Security reports

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/tw93/Kaku/security/advisories/new) rather than in a public issue. Include the affected Kaku version, the impact, and a reproduction path. You will get an acknowledgement in the advisory thread, and a fix ships in a normal release with credit unless you ask otherwise.
