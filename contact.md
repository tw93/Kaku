# Contact

Kaku is open source, and all support happens in public except security reports.

## Bugs and feature requests

Open an issue at [github.com/tw93/Kaku/issues](https://github.com/tw93/Kaku/issues). It is the fastest channel, and the maintainer reads issues directly. Search first, since many install and AI setup questions already have answers.

To help reproduce the problem, include:

- Install method: DMG or `brew install --cask kaku`.
- macOS version and chip (Apple Silicon or Intel).
- Kaku version, from `kaku --version`.
- Output of `kaku doctor`, which checks the app bundle, config directory, PATH, shell integration, and optional tools.
- Steps to reproduce, and what you expected to happen.

## Questions and ideas

Usage questions, config help, and ideas that are not bugs yet go to [GitHub Discussions](https://github.com/tw93/Kaku/discussions). The [FAQ](https://kaku.fun/docs/faq) and [Configuration](https://kaku.fun/docs/configuration) page already answer many of them.

## Security reports

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/tw93/Kaku/security/advisories/new), not in a public issue. Include the affected version, the impact, and how to reproduce it. You will get a reply in the advisory, and the fix ships in a regular release with credit to you unless you would rather not be named.
