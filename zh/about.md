# 关于 Kaku

一个开箱即用、默认好用、AI 友好的 Mac 终端，由 Tw93 开发和维护。

## Kaku 是什么

Kaku 是基于 [WezTerm](https://wezterm.org) 的 Mac 终端，预设了 JetBrains Mono、跟随系统的深浅色主题，以及标签页和分屏快捷键。Shell 补全、语法高亮和目录跳转已经配好，Lazygit、Yazi 等工具可以按需安装，也可以用 Lua 自定义终端。

名字取自日语 書く（kaku），意为书写。Kaku 属于同一作者的一个小家族：Kaku 写代码，[Waza](https://github.com/tw93/Waza)（技）练习惯，[Kami](https://github.com/tw93/Kami)（紙）做文档。

## 谁在做

Kaku 由独立开发者 Tw93 开发，他也是 [Pake](https://github.com/tw93/Pake) 和 [Mole](https://github.com/tw93/Mole) 的作者。开发全程公开在 GitHub 上：issue、PR、发布和路线图都能看到，源码 MIT 开源。支持渠道是 [GitHub Issues](https://github.com/tw93/Kaku/issues)，也可以通过 [GitHub Sponsors](https://github.com/sponsors/tw93) 支持开发。

## 使用 Kaku

- **无需 Kaku 账号。**没有注册、没有登录、没有云端中转，装上就能用。
- **不做埋点。**Kaku 不采集使用数据，App 会发起的网络请求全部列在[隐私](https://kaku.fun/zh/privacy)页面。
- **自行配置 AI。**用 `kaku ai` 配置自己的 AI 服务，Kaku 不提供或中转 AI 服务，网络请求说明见[隐私页](https://kaku.fun/zh/privacy)。
- **仅支持 macOS。**目前只支持 macOS，Windows 和 Linux 未支持，也不承诺时间表。
- **不收费。**Kaku 免费且 MIT 开源，没有付费档位。

## 怎么用这个站点

每个页面都有 markdown 孪生版本：在任意 URL 后面加 `.md`，或者请求头带 `Accept: text/markdown`，拿到的是去掉页面外壳的同一份正文。[llms.txt](https://kaku.fun/llms.txt) 是精简索引，[llms-full.txt](https://kaku.fun/llms-full.txt) 是给语言模型和答案引擎用的完整单文件说明。

可以从[文档](https://kaku.fun/zh/docs/)开始，用[路线图](https://kaku.fun/zh/roadmap)了解正在做什么，或者[联系我们](https://kaku.fun/zh/contact)。
