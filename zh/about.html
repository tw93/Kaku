关于 Kaku

一个开箱即用、默认好用、AI 友好的 Mac 终端，由 Tw93 开发和维护。

Kaku 是什么

Kaku 是基于 WezTerm 的 Mac 终端，JetBrains Mono、跟随系统的深浅色主题、标签和分屏快捷键都预设好了，Shell 补全、语法高亮和目录跳转也已经配好，Lazygit、Yazi 这些工具按需安装，想再细调就用 Lua。

名字取自日语的 書く（kaku），意思是书写，它和 Waza（技）、Kami（紙）出自同一个作者，Kaku 写代码，Waza 练习惯，Kami 做文档。

谁在做

Kaku 由独立开发者 Tw93 开发，他也做了 Pake 和 Mole，开发全程在 GitHub 上公开，issue、PR、发布和路线图都能看到，源码 MIT 开源，有问题去 GitHub Issues 提，想支持开发可以走 GitHub Sponsors。

使用 Kaku

  • 无需 Kaku 账号。没有注册、没有登录、没有云端中转，装上就能用。
  • 不做埋点。Kaku 不采集使用数据，App 会发起的网络请求全部列在隐私页面。
  • 自行配置 AI。用 kaku ai 接你自己的 AI 服务，Kaku 不提供也不中转。
  • 仅支持 macOS。Windows 和 Linux 暂不支持，也不承诺时间表。
  • 不收费。Kaku 免费且 MIT 开源，没有付费档位。

从哪开始看

可以从文档开始，从 iTerm2、Warp、Ghostty 或 WezTerm 换过来的话先看终端对比，想知道接下来在做什么看路线图，其他事情见联系页面。
