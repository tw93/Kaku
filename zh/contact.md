# 联系

Kaku 是开源项目，除了安全报告，其他问题都在公开渠道里交流。

## Bug 与功能建议

去 [github.com/tw93/Kaku/issues](https://github.com/tw93/Kaku/issues) 提 issue，这是最快的渠道，维护者会直接看，提之前先搜一下，安装和 AI 配置这类问题很多已经有人问过了。

附上这些信息，方便复现：

- 安装方式：DMG 还是 `brew install --cask kaku`。
- macOS 版本和芯片（Apple Silicon 还是 Intel）。
- Kaku 版本，运行 `kaku --version` 查看。
- `kaku doctor` 的输出，它会检查 App 包、配置目录、PATH、shell 集成和可选工具。
- 复现步骤，以及你原本期望看到什么。

## 提问与想法

用法和配置上的疑问，或者还算不上 bug 的想法，发到 [GitHub Discussions](https://github.com/tw93/Kaku/discussions)，不少答案其实已经写在 [FAQ](https://kaku.fun/zh/docs/faq) 和[配置](https://kaku.fun/zh/docs/configuration)页里，可以先翻一下。

## 安全报告

安全漏洞通过 [GitHub Security Advisories](https://github.com/tw93/Kaku/security/advisories/new) 私下报告，别开公开 issue，写清受影响的版本、影响范围和复现方式。维护者会在这个 advisory 里回复，修复跟着正常版本发布，默认会致谢，不想署名说一声就行。
