01 · 标签与分屏

标签和分屏，还是 Mac 上那套快捷键

⌘T 开标签，⌘D 分屏，⌘1 到 ⌘9 切换，右键可以粘贴、搜索或打开 AI 对话，退出后再打开 Kaku，窗口、分屏和各自的目录都还在。

02 · 助手

命令报错，不该只剩一行红字

配好助手后，命令跑错了它会给出改好的写法，按 Cmd + Shift + E 放回命令行，执不执行还是你来决定，想不起命令怎么写时，输入 # 加一句大白话也行。

了解助手

~/proj $ npm run buidl

npm ERR! Missing script: "buidl"

Kaku Assistant · 建议修复
npm run build
按 ⌘⇧E 放回命令行，不会自动执行。

~/proj $ npm run build

04 · 上手

从这里开始

装完直接用，AI 服务和其他设置等用到时再配。

01

安装

下载 DMG 或运行 brew install --cask kaku，装完跑一次 kaku doctor，看看 app、PATH 和 shell 集成是否正常。

02

AI 设置

运行 kaku ai 填上自己的 AI 服务和模型，之后按 Cmd + L 就能打开 AI 对话。

03

工具

Cmd + Shift + G 打开 Lazygit，Cmd + Shift + Y 打开 Yazi，在 SSH 会话里按 Cmd + Shift + R 可以挂载远端文件。

04

配置

运行 kaku config，在终端里改字号、透明度、Smart Tab、关闭确认和快捷键，更细的地方用 Lua 覆盖。

05 · 为什么是 Kaku

先是我自己天天在用

我工作和生活里的事大多在命令行里做，之前用了很久 Alacritty，可它没有多标签，做 AI 编码时很不方便，其他几款也试过，总有字体、窗口或者要登录这类小问题，我想要一个装好就能用、不用先写一堆配置的终端，于是做了 Kaku。

06 · 问答

常见问题

怎么安装？
从 GitHub Releases 下载 DMG，或用 Homebrew 安装：brew install --cask kaku。
和 iTerm2、Warp、Ghostty、WezTerm 比有什么不同？
简单说就是字体、主题和 Shell 工具开箱配好，不用注册账号，AI 服务用你自己的，每一款的具体差别写在对比页里。
Kaku 收费吗？
不收费，Kaku 是 MIT 协议的开源项目。
支持 Windows 或 Linux 吗？
暂时不支持，眼下先把 Mac 上的体验做好。
