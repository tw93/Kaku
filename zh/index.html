从这里开始

装完直接用，AI 服务和其他设置等用到时再配。

01

安装

下载 DMG 或运行 brew install --cask kaku，打开 Kaku 就能开始用。

02

AI 设置

需要 AI 时，运行 kaku ai，沿用 Codex 的连接或配置自己的 API 服务，之后按 Cmd + L 就能打开 AI 对话。

03

工具

Cmd + Shift + G 打开 Lazygit，Cmd + Shift + Y 打开 Yazi，在 SSH 会话里按 Cmd + Shift + R 可以挂载远端文件。

04

配置

运行 kaku config，在终端里改字号、透明度、Smart Tab、关闭确认和快捷键，更细的地方用 Lua 覆盖。

起初是我自己天天在用

我工作和生活里的事大多在命令行里完成。之前用了很久 Alacritty，但它没有多标签，做 AI 编程时很不方便，其他几款也试过，总有字体渲染、窗口细节或强制登录这类小遗憾。我想要一个开箱即用、不用先写一堆配置的终端，于是做了 Kaku。

常见问题

怎么安装？

下载 DMG，或用 Homebrew 安装：brew install --cask kaku。

Kaku 收费吗？

不收费，Kaku 是 MIT 协议的开源项目。

支持 Windows 或 Linux 吗？

暂时不支持，眼下先把 Mac 上的体验做好。

一定要用 AI 吗？

不用。AI 功能跑在你自己的 Codex 连接或在 kaku ai 里配好的 API 服务上，不配的话终端其他部分照常用。

能用我的 WezTerm 配置吗？

大多可以，Kaku 沿用 WezTerm 的 Lua 配置，少数选项表现不同，可以先看配置文档。

怎么更新？

运行 kaku update，或在菜单里点 Check for Updates，用 Homebrew 装的也可以运行 brew upgrade --cask kaku。
