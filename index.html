Get started

First steps

Install it and go. Set up AI and the rest when you need them.

01

Install

Grab the DMG or run brew install --cask kaku, then open Kaku and start working.

02

AI setup

When you need AI, run kaku ai to use your Codex connection or configure an API service, then press Cmd + L to open chat.

03

Tools

Cmd + Shift + G for Lazygit, Cmd + Shift + Y for Yazi, and Cmd + Shift + R to mount remote files in an SSH session.

04

Config

Run kaku config to change font size, opacity, Smart Tab, close confirmation, and shortcuts right in the terminal. Anything deeper goes in Lua.

Why Kaku

It started as my own daily driver

Most of my work and life runs through the command line. I used Alacritty for a long time, but without tabs it got in the way once I started coding with AI. The other terminals I tried each had something, whether font rendering, window quirks or a required login, and I wanted one that works well the moment it is installed, without a pile of config first. So I built Kaku.

Questions

Common questions

How do I install Kaku?

Download the DMG, or install with Homebrew: brew install --cask kaku.

Is Kaku paid?

No, Kaku is an MIT-licensed open source project.

Does Kaku run on Windows or Linux?

Not yet. For now the focus is making it great on the Mac.

Do I have to use the AI?

Only if you want it. The AI features run on your own Codex connection or an API service you set up in kaku ai, and the rest of the terminal works the same without them.

Can I bring my WezTerm config?

Mostly. Kaku keeps WezTerm's Lua config, though a few options behave differently, so check the configuration guide.

How do I update Kaku?

Run kaku update or choose Check for Updates in the app menu. If you installed with Homebrew, brew upgrade --cask kaku works too.
